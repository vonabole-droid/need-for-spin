# Советский Need for Spin

Браузерная 3D-игра по мотивам настольной игрушки с вращающимся диском: машинка стоит на магните, под ней крутится трасса с мостами и тоннелями.

Играть: https://vonabole-droid.github.io/need-for-spin/

## Управление

- Пробел — завести / заглушить мотор
- ←/→ или A/D — руль
- W/S или 0–3 — скорость
- R — вернуть машинку на магнит
- C или двойной клик — камера, B — фон (студия/кухня)
- Q — качество графики, T — настройки физики, M — звук
- Геймпад: стик — руль, A — мотор, LB/RB — скорость

## Устройство

Один файл `index.html` на Three.js (грузится с CDN), без сборки. Физика своя: пружина магнита с демпфером, трение о диск, столкновения с опорами мостов и отбойниками, срыв с магнита.

Старые версии лежат в `versions/`: 2D-прототип, первый 3D и look-dev с кухней.
